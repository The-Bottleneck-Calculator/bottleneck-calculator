## 📊 Technical Architecture & System Balance Logic
Modern video game engines distribute processing tasks dynamically across multi-threaded processing environments. When hardware components are mismatched, system performance degrades into specific architectural states:

1. **Processor-Bound State:** High CPU utilization ($100\%$) paired with low GPU utilization ($<80\%$). Common when running high-frame-rate engines at 1080p resolution.
2. **Graphics-Bound State:** Low CPU utilization ($<40\%$) with maxed GPU utilization ($95\%-100\%$). This represents optimal component synergy for high-fidelity 1440p and 4K resolution rendering profiles.
3. **Thermal Throttling Thresholds:** Silicon protection limits drop component utilization percentages to preserve structural hardware longevity when active cooling dissipation layers fail.
